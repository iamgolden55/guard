# Manager Quick Reference: Incomplete Shifts

## 🚀 Quick Start Guide

### Accessing the Feature
1. Navigate to **http://localhost:3003/approvals**
2. Click the **"Incomplete Shifts"** tab
3. Review shifts needing attention

### Understanding the Dashboard

#### Priority Levels
- 🔴 **HIGH** (Red): >2 hours overdue - **Immediate action required**
- 🟡 **MEDIUM** (Yellow): 0.5-2 hours overdue - **Action needed soon**
- 🟢 **LOW** (Green): <0.5 hours overdue - **Monitor**

#### Issue Types
- 🔴 **NO CHECK-IN**: Staff should have checked in but didn't
- 🟡 **NO CHECK-OUT**: Staff checked in but didn't check out

#### Status Indicators
- ✅ **Auto-Checkout Eligible**: System can handle automatically
- ❌ **Not Eligible**: Requires manual intervention
- ⚠️ **Force Timeout Ready**: 12-hour bypass available
- ⏳ **Pending**: Still within normal timeframes

## 🛠️ Manager Actions

### 1. Manual Check-in
**When to use**: Staff worked but couldn't check in (network issues, app crash)

**Steps**:
1. Click **"Manual Check-in"** button
2. Enter your full name as signature
3. Add notes explaining the situation
4. Adjust check-in time if needed
5. Click **"Check In"**

**Example scenario**: Sarah arrived on time but had no mobile signal to check in

### 2. Manual Check-out
**When to use**: Staff completed shift but couldn't check out

**Steps**:
1. Click **"Manual Check-out"** button
2. Enter your full name as signature
3. Input actual hours worked
4. Add notes explaining the situation
5. Adjust check-out time if needed
6. Click **"Check Out"**

**Example scenario**: John finished his shift but app crashed during checkout

### 3. Force Complete
**When to use**: Complete shift creation for exceptional circumstances

**Steps**:
1. Click **"Force Complete"** button
2. Enter your full name as signature
3. Input actual hours worked (required)
4. Set check-in time
5. Set check-out time
6. Add detailed notes explaining the situation
7. Click **"Force Complete"**

**Example scenario**: Sarah worked full shift but network issues prevented both check-in and check-out

## 📝 Best Practices

### Required Information
- **Manager Signature**: Your full name (legally binding)
- **Manager Notes**: Clear explanation of the situation
- **Evidence**: Reference any supporting documentation

### Note Examples
✅ **Good**: "Manual check-in due to network outage at venue between 8:00-8:30 PM. Staff confirmed present by venue manager."

❌ **Poor**: "Network issues"

### Time Accuracy
- Use actual work times, not scheduled times
- Account for any breaks or early departures
- Round to nearest 15-minute increment per company policy

## 🔍 Common Scenarios

### Network Issues
**Problem**: Staff at venue but can't access app
**Solution**: Use "Manual Check-in" with current time, note network issue

### Device Problems
**Problem**: Staff phone died during shift
**Solution**: Use "Force Complete" with actual start/end times

### Emergency Situations
**Problem**: Staff had to leave suddenly for emergency
**Solution**: Use "Manual Check-out" with actual departure time

### New Staff Training
**Problem**: New employee forgot to check in
**Solution**: Use "Manual Check-in" with actual arrival time

## ⚠️ Important Reminders

### Legal Compliance
- All actions create permanent audit records
- Manager signature has legal implications
- Accurate time recording required for payroll compliance

### Payroll Impact
- Manual hours affect staff payment
- Double-check calculations before submitting
- Coordinate with payroll team for unusual circumstances

### Documentation
- Keep supporting evidence (photos, witness statements)
- File any incident reports as required
- Update staff training records if needed

## 🆘 Troubleshooting

### Can't See Incomplete Shifts
- Check your user permissions (manager/admin required)
- Refresh the page
- Clear browser cache

### Actions Not Working
- Verify all required fields are filled
- Check internet connection
- Try refreshing the page

### Data Not Updating
- Allow a few seconds for processing
- Refresh the page manually
- Check if shift moved to different status
