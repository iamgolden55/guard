# Deputy: Comprehensive Documentation

## 1. Introduction to Deputy

Deputy is a cloud-based workforce management platform designed to streamline employee scheduling, time tracking, task management, and team communication. Founded in 2008, Deputy has evolved into a comprehensive solution that helps businesses manage their workforce efficiently across various industries.

Deputy serves as an all-in-one platform that enables businesses to:
- Create and manage employee schedules
- Track employee time and attendance
- Manage payroll integration
- Handle task assignments and communication
- Ensure compliance with labor regulations
- Provide insights through reporting and analytics

The platform is designed to be user-friendly and accessible, with both web-based interfaces and mobile applications that allow managers and employees to interact with the system from anywhere. Deputy's ecosystem is built to integrate with various other business software solutions, creating a connected environment that enhances operational efficiency.

Deputy's core philosophy centers around simplifying workforce management while providing powerful tools that adapt to businesses of all sizes, from small operations to large enterprises with complex scheduling and compliance needs. The platform aims to reduce administrative burden, improve communication, and provide data-driven insights to optimize workforce operations.

In this comprehensive documentation, we will explore Deputy's complete ecosystem, including its features, functionality, pricing structure, integration capabilities, and how businesses can leverage the platform to improve their workforce management processes. We will also delve into the technical aspects of Deputy's API and data extraction capabilities, which are particularly relevant for businesses looking to integrate Deputy with other software systems or migrate data to new platforms.
# Deputy Core Features and Functionality

## 2.1 Shift Scheduling and Assignment

Deputy's scheduling capabilities form the backbone of its workforce management system, allowing businesses to create, manage, and optimize employee schedules efficiently.

### Schedule Creation and Management
- **Intuitive Scheduling Interface**: Deputy provides a drag-and-drop interface that makes creating and adjusting schedules simple and visual.
- **Template-Based Scheduling**: Businesses can create schedule templates for recurring shifts, saving time and ensuring consistency.
- **Auto-Scheduling**: The platform can automatically generate schedules based on employee availability, skills, certifications, and labor costs.
- **Shift Swapping**: Employees can swap shifts directly with suitable team members via the Deputy app, reducing manager workload.
- **Open Shifts**: Managers can publish open shifts that eligible employees can claim on a first-come, first-served basis.
- **Schedule Templates**: Create and save schedule templates for quick application to future periods.

### Demand-Based Scheduling
- **Labor Forecasting**: Deputy uses historical data and business metrics to predict staffing needs.
- **Demand Planning**: The system helps match staffing levels to expected business demand, optimizing labor costs.
- **Budget Controls**: Managers can set and monitor labor budgets while creating schedules to avoid overstaffing.

### Compliance and Rules
- **Break Planning**: Automatically schedule required breaks based on shift length and labor laws.
- **Fatigue Management**: The system can alert managers to potential employee fatigue issues based on scheduled hours.
- **Qualification Tracking**: Ensure only properly qualified employees are scheduled for specific roles or tasks.
- **Compliance Alerts**: Receive notifications about potential compliance issues in schedules before they're published.

### Schedule Communication
- **Instant Notifications**: Employees receive immediate notifications about new schedules or schedule changes.
- **Confirmation Requirements**: Managers can require employees to confirm receipt of schedules or schedule changes.
- **Calendar Integration**: Schedules can sync with employees' personal calendars for better planning.

## 2.2 Time and Attendance Tracking

Deputy provides robust time tracking capabilities that ensure accurate attendance records and streamline payroll processing.

# Technical Implementation and Data Migration

## 6.1 API Implementation for Data Extraction

For businesses looking to extract data from Deputy for use in other systems, understanding the technical implementation details of Deputy's API is essential.

### API Architecture Overview

Deputy's API follows RESTful principles and is designed to provide comprehensive access to the platform's data and functionality. Key architectural aspects include:

- **Endpoint Structure**: API endpoints are based on the customer's Deputy subdomain
  - Example: `https://example.au.deputy.com/api/v1/resource/Employee`
- **API Versions**: Most endpoints use `/api/v1`, with newer features using `/api/v2`
- **Response Format**: All API responses are in standard JSON format
- **Request Methods**: Standard HTTP methods (GET, POST, PUT, DELETE) for different operations
- **Rate Limiting**: Maximum of 500 records per response with pagination for larger datasets
- **Authentication**: OAuth 2.0 or permanent token authentication

### Authentication Methods in Detail

#### OAuth 2.0 Implementation
1. **Registration**: Register your application in Deputy to obtain client credentials
2. **Authorization**: Redirect users to Deputy's authorization endpoint
3. **Token Exchange**: Exchange authorization code for access token
4. **Token Usage**: Include access token in API requests
5. **Token Refresh**: Use refresh tokens to maintain access without re-authorization

#### Permanent Token Implementation
1. **Token Generation**: Generate permanent API token in Deputy admin settings
2. **Authorization Header**: Include token in Authorization header for all requests
3. **Security Considerations**: Store token securely as it provides ongoing access

### Common API Operations

#### Retrieving Employee Data
```
GET https://{subdomain}.deputy.com/api/v1/resource/Employee
```
